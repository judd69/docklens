What it checks

Twenty-five rules, DL01–DL25, across four areas.

SecuritySecrets in ENV and secret ARGs in RUN, curl piped to a shell, root users, ADD fetching URLs, .env copied into the image, EXPOSE 22, chmod 777, sudo in build steps.
EfficiencyUnpinned and :latest bases, apt without --no-install-recommends or layer cleanup, split update/install layers, COPY . . before dependency install, apk / pip / npm hygiene.
ReliabilityShell-form CMD/ENTRYPOINT swallowing signals, missing HEALTHCHECK, missing WORKDIR, multi-stage builds that never COPY --from the artifact.
MaintainabilityDeprecated MAINTAINER, digest-pinning hints, and a readable score so the worst file in the repo is obvious.

Outputs

Coloured text for humans, JSON for pipelines, and a single self-contained HTML report — like the sample report — with severity filters and click-to-source. Exit codes: 0 pass, 1 gate tripped, 2 usage or file error.
